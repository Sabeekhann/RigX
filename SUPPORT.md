# Support

RIGX is currently an alpha open-source project.

## Questions and usage help

For reproducible usage questions, open a GitHub issue using the appropriate template and include:

- RIGX version/commit;
- Node.js version;
- operating system;
- command used;
- sanitized output;
- a minimal public reproduction when possible.

## Feature ideas

Use the feature-request issue form. Explain the harness-engineering problem first; implementation suggestions are welcome but secondary.

## Security or privacy problems

Do **not** use public support issues for vulnerabilities or sensitive data disclosures. Follow [SECURITY.md](SECURITY.md).

## What is not yet supported

RIGX is pre-1.0. There is not yet a stable npm release, hosted dashboard, or compatibility guarantee for vendor-internal transcript formats.
